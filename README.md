# Typing Race Simulator
Author: Evleen Manghera

Version: 2

## What the project does
This project is a Typing Race Simulator that allows users to simulate a race based on typing accuracy and performance. The game calculates outcomes based on predefined attributes such as accuracy and speed. It is split into two parts:
- **Part 1:** A text-based version with limited functionality.
- **Part 2:** A graphical user interface (GUI) version with extended features and improved interaction.

## Why the project is useful
This project demonstrates key programming concepts such as object-oriented design, data validation, sorting algorithms, and user interaction. It is useful for learning how logic-based simulations work and how a simple program can be expanded from a basic console application into a fully interactive GUI application.

## How users can get started
1. Download or extract the project files.
2. Open the project in a Java-compatible IDE such as IntelliJ IDEA, Eclipse, or VS Code.
3. Ensure you have Java installed on your system (Java JDK required).
4. Locate the main class file for either Part 1 or Part 2.

## Instructions to compile and run

### Part 1 - Text-Based Version
1. Open a terminal or command prompt.
2. Navigate to the folder containing the Part 1 source files
3. Compile the program using:
   ```
   javac *.java
   ```
4. Run the program using:
   ```
   java TypingRace
   ```

### Part 2 - GUI Version
1. Open a terminal or command prompt.
2. Navigate to the folder containing the Part 2 source files.
3. Compile the program using:
   ```
   javac *.java
   ```
4. Run the program using:
   ```
   java Main
   ```
5. The graphical interface will open, allowing you to interact with the game visually.

## HELP: Navigating to the folder
1. Check where the folder is stored using file explorer, get the file path of the folder
2. Navigate to the project folder using cd ---
    ```
   Example: cd Desktop\TypingRaceSimulator
   ```
